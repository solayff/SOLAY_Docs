# الدخول لمدينة سولايف

## كيف يمكنك الدخول ؟

يمكنك الدخول لسيرفر سولايف عن طريق البحث عن "سولايف" أو عن طريق الآي بي الخاص في السيرفر الموجود في [**مجتمع سولاي**](https://discord.gg/so)


**بعد تحميل ملفات السيرفر عند دخولك سوف تواجهك أسئلة نحدد منها فهمك وهل لديك معرفة للقوانين او لا وعند اجتيازك للأسئلة يمكنك انشاء شخصة اللعب في سيرفر سولايف بكل راحة .**

:::caution

**تذكر يجب تشغيل برنامج التصوير قبل دخول السيرفر لكي تضمن حقك كذالك هناك تفتيش دوري**

:::
