# إنشاء شخصية جديدة

## شرح انشاء شخصية جديدة 
-------------------------------------

1- اضغط على علامة ال + في الأسفل 

2- تختار جنس الشخصية سواء كان ذكر او أنثى 

3- قم بكتابة الاسم الأول للشخصية (بدون مسافات)

4- قم بكتابة الاسم الثاني للشخصية أو اسم العائلة للشخصية (بدون مسافات)

5- قم بإختيار جنسية الشخصية أو مكان ميلاد الشخصية

6-  قم بتحديد عمر الشخصية ( تاريخ ميلاد الشخصية ) سنة/يوم/شهر

7- بعد الأنتهاء اضغط على **CREATE**
